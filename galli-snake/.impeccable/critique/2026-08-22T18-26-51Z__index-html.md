But everything the player interacts with is generic: green block snake, orange glow-dot "apple pellet" food, boilerplate HUD ("Score:", "Best:"), default monospace, stock overlay copy. ## Cognitive Load
Failed item: working memory (invisible difficulty ramps, implicit scoring rules, lethal boundaries discovered empirically). Borderline: visual hierarchy (food glow wins; scenery luminance near gameplay). Decision points >4: none — steering only, four options.

## Emotional Journey
Clean entry, flat exit. Deaths arrive silently (speed steps unannounced) so sudden deaths feel like betrayal; the most-replayed moment (death) swaps instantly to an overlay identical to the idle screen — no beat, no cause, no celebration of PB moments. Peak-end rule says invest in death + PB-passed moments next.

## What's Working
- Procedural street scene: seeded, deterministic, layered detail, pre-rendered offscreen once — the seed of the game's identity.
- Input plumbing above Day-1 bar: event.repeat filtered, preventDefault scroll-kill, non-passive touch listeners + touch-action:none, swipes anywhere, correct tail-vacate collision.
- Restart ergonomics: 0.5s rage-tap lockout; pressing Right after death starts the new run already heading right.

## Priority Issues
1. **[P1] Direction queue eats valid inputs** — ↑ then ← within one tick: ← overwrites ↑, then gets rejected as reversal; both lost, snake sails into danger. Kills skilled corner-cutting; feels unfair. Fix: FIFO depth 2–3, validate against current direction at dequeue (~10 lines in src/game/logic.ts).
2. **[P2] Silent difficulty ramp + stale Best** — no signal at speed-up; Best doesn't flip mid-run when passed. Fix: HUD pulse/"Speed up!" flash on ramp; live-update Best.
3. **[P2] No pause or resume grace** — returning from app-switch hands you a moving snake instantly; no deliberate pause exists. Fix: visibilitychange → "Get ready…" veil ~1s.
4. **[P3] Death moment has no beat** — add 300–500ms freeze/red flash on fatal cell + cause line ("You hit the lane wall" / "You ran into yourself").
5. **[P3] Food and snake unthemed** — vada pav should be golden-brown disc with pav highlight; even one head tint/garnish ties actor to fantasy cheaply. drawSegment already isolated for this.

## Persona Red Flags
- **Jordan (first-timer)**: rules never stated (walls kill, speed rises); ↑-to-start moves right regardless; bare "Game Over" teaches nothing about which rule killed you.
- **Casey (distracted mobile)**: app-switch return = instant motion, unfair death likely; no way to stop a run voluntarily; 24px swipe threshold turns jitter into committed turns.
- **Riley (stress tester)**: queue-overwrite bug punishes fast double-tap cornering; bare modifier keys count as "any key"; placeFood board-full sentinel {x:-1,y:-1} would render food off-grid forever.
